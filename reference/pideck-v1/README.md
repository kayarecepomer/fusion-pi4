# PiDeck V1 source files (reference only)

These are the original files of **PiDeck – 7 Inch Cyberdeck with Raspberry Pi 5** by **Screase3D**,
from <https://makerworld.com/en/models/2619704-pideck-7-inch-cyberdeck-with-raspberry-pi-5>.

as the reference for the foldable remix. The remix in this repo is a derivative, so it carries the same license:
credit Screase3D, non-commercial only, share alike.

| `stl/Main_Display_Frame.stl` | Front frame, holds display and keyboard | 184.0 × 201.3 × 19.3 |
| `stl/Main_Display_Frame_Rii_Spacer.stl` | Shim under the keyboard | 166.0 × 58.9 × 2.6 |
| `stl/Pi_Mounting_Base.stl` | Internal chassis the Pi stack bolts to | 177.4 × 195.7 × 36.0 |
| `stl/Pi_Mounting_Base_IO_Plate.stl` | I/O cut-out plate | 100.3 × 31.8 × 2.3 |
| `stl/Battery_Housing.stl` | Power bank compartment | 170.2 × 81.0 × 32.0 |
